# Pacotes de revisão do banco SUPERADOS

Os três ZIPs desta pasta são entregas de rodadas anteriores e descrevem o banco com **36, 40 e 50 migrations** e com pendências que **já foram corrigidas**
(`refresh_tokens`, referência entre empresas, livros mutáveis, `ON DELETE CASCADE`, escopo por filial, travas de privilégio). Não use como referência do estado atual.
`SHA256SUMS-revisao-banco-corrigido-2026-10-15.txt` é o manifesto do ZIP de 50 migrations (2026-10-15), mantido para conferir o arquivo histórico.

O pacote vigente é `docs/CORTEX/CORTEX-finalizacao-producao-2026-10-15.zip` (**52 migrations**), com o manifesto
`docs/CORTEX/SHA256SUMS-finalizacao-producao-2026-10-15.txt` (hash de cada arquivo e do próprio ZIP).
