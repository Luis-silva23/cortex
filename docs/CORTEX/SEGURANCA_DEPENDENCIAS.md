# Vulnerabilidades de dependências — análise por advisory (2026-10-22)

> Fonte: `npm audit` (registro do npm, 2026-10-22) sobre o `package-lock.json` do commit `1477fe1`: **96 pacotes afetados — 0 críticos, 69 altos, 27 moderados (51 em dependências de produção)**. Só **12 pacotes têm advisory própria** (25 advisories); os outros 84 apenas **herdam** a vulnerabilidade de um desses (Expo/React Native, Jest, electron-builder, ESLint do Next). `npm audit fix` não funciona nesta versão do npm (o serviço foi aposentado), então as correções foram feitas por atualização dirigida do lock (ver [HOMOLOGACAO_POS_NEXT15 §5](HOMOLOGACAO_POS_NEXT15.md)).
>
> **Como ler a exposição:** "produção" significa que o pacote vai para um artefato que roda para clientes (API, bundle do navegador, imagem). "Build/dev" significa que só roda na máquina de quem desenvolve ou no CI. **Incerteza declarada:** a classificação vem do caminho de dependência (`npm ls`), da leitura do uso no código e dos textos dos advisories; **não** houve tentativa de explorar nenhuma delas.

## 2. O que foi corrigido nesta rodada

`express` 4.22.2 → 4.22.3, `body-parser` 1.20.6 → 1.20.9, `qs` 6.15.3 → 6.16.1, `fast-uri` 3.1.7 → 3.1.9, `joi` 17.13.7 → 17.13.8 (só o `package-lock.json`, dentro do intervalo já declarado): **101 → 96**. Antes, `proxy-addr` 2.0.8 e `bcrypt` 6 (commits `3f8d4c1` e `ccf9ad4`). O Next foi de 14.2.35 para 15.5.28, o que zerou os críticos.
